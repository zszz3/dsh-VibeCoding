# AGENTS.md — Agent Notes(中文对照)

[English 原文](AGENTS.md) | 中文

Agent Note 实际上就是 agent(智能体)写的 RFC:持久的提案与决策记录,保住理由、备选方案、后果以及必需的验证。遵循[文档标准](../../docs/AGENTS.zh.md)与 [Agent Note 规则](README.md)。

**每新增一篇 Agent Note 都要触发一次取代检查。** 在活跃的记录树里搜索是否有更早的记录讲同一个决策或机制,用 [`dsh-archive-agent-notes`](../skills/dsh-archive-agent-notes/SKILL.zh.md) 判定属于完全取代还是部分取代,并在同一个 PR 里归档每一组符合条件的已实现三件套。部分取代的两篇都保持活跃并互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照:绝不编辑它们,也不把它们当作当前依据。
